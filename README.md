# Henk du Plessis — Portfolio

A responsive one-page portfolio presenting Henk's project-delivery experience, the VeldFlow modular operating-platform vision, current software skills and training path.

## Open locally

Open `index.html` in a browser. No build step or installation is required.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year

## Personalise next

Replace or add project links as more work becomes public. The skills language deliberately distinguishes established professional experience from developing software skills.
